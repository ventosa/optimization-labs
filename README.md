## Задание 1. Вывести рекуррентное уравнение для задачи о рюкзаке
Что сделать. Для 0/1 рюкзака сформулировать $V_k(w)$ — максимальную ценность из первых $k$ предметов при вместимости $w$. Выписать рекуррентное уравнение и граничные условия. Объяснить, почему принцип оптимальности Беллмана выполняется: почему оптимальное решение для $k$ предметов содержит оптимальное решение для $k−1$.

Сдать: вывод в markdown-ячейке ноутбука, 1–2 абзаца обоснования.

## Задание 2. Найти ошибку в рекуррентном уравнении
Что сделать. Дано рекуррентное уравнение для неограниченного рюкзака:
$$V(w)=\max_{i: w_i \leq w} V(w−w_i)+v_i$$
Проверить, корректно ли оно для 0/1 рюкзака. Найти контрпример, где оно даёт неверный ответ. Объяснить, почему для 0/1 нужен дополнительный индекс $k$.

Сдать: контрпример (конкретные $w_i, v_i, W), исправленное уравнение.

## Задание 3. Три способа решить 0/1 рюкзак
Что сделать. Реализовать: 
- наивную рекурсию без мемоизации;
- top-down с мемоизацией (словарь или lru_cache);
- bottom-up DP с 1D-массивом (обратный проход по $w$).

Проверить, что все три дают одинаковый ответ на 20 случайных экземплярах при $n \leq 12$. Замерить время на 
$n=25$ и $W=1000$.

Сдать: код, таблица «метод × время», вывод: во сколько раз memo быстрее наивного.
